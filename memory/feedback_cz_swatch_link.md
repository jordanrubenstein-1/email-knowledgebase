description: Correct destination URL for The Citizenry swatch campaigns (SMS and email)
type: feedback

For any CZ (The Citizenry) campaign promoting swatches, the link must go to the swatches page, not the homepage.

**Correct URL:** https://www.the-citizenry.com/collections/swatches-bedding

**Why:** A swatch push SMS was built with the homepage URL by mistake. The correct destination is the bedding swatches collection page.

**How to apply:** Whenever building or reviewing a CZ campaign (SMS, email, or push) that mentions swatches or free swatches, verify the CTA link points to `/collections/swatches-bedding`, not the homepage or any other URL.
