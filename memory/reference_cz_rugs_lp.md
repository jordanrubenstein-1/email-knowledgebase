The Citizenry's Rugs collection LP (used for "Shop Rugs" CTAs) is:

`https://www.the-citizenry.com/collections/shop-all-rugs-1`

**Do not use:**
- `https://www.the-citizenry.com/collections/rugs` (doesn't exist / wrong pattern)
- `https://www.the-citizenry.com/collections/fall-2025-rugs` (a seasonal/dated collection — was mistakenly used in a CZ Monthly Edit brief, Slice 3 "Rugs for Fall", and had to be corrected)

Also documented in CLAUDE.md under "Campaign URLs & Discounts" as **CZ Rugs LP**. See [[feedback_cz_product_brief_archive_sale]] for the related rule on never guessing/inventing CZ product or collection URLs.
